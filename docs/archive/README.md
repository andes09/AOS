# Archive

This holds planning material from before the 2026-07-13 pivot, when the
product (then "AgileOS") was a Jira-connected sprint-planning copilot —
ticket sync, skill-based routing, inline ticket refinement, "Sprint Brain"
plan generation, Scope Cop, the whole Jira onboarding path.

That product direction was torn down (see the `chore: delete Jira
integration`, `chore: delete Scope Cop backend implementation`, and `chore:
drop legacy Jira schema` commits) in favor of Omada: a GitHub-connected,
purpose-steered project roadmap generator. None of the code, contracts, or
schemas described in `plans/` reflect the current backend or frontend.

Kept for historical reference only — do not build against anything in here.
Current architecture and integration docs live in `docs/` directly; see
`docs/pivot-roadmap-ai.md` for the product overview.
